# Charlie King - Local Favorites Tracker 

A local favorites tracking web app built for WRIT 40363. /it allows users to add, rate, and filter their favorite spots, movies, and tv shows, saving them locally in the browser so they persist between visits. 

**Live site:** 
https://charlottesking.github.io/Project02-King/ 

##

- Semantic HTML5 with accessible form controls 
- CSS with design tokens, custom properties, and CSS Grid 
- Vanilla JavaScrit (ES6) with DOM manipulation and event listeners 
- Web Storage API ('localStorage') with JSON parsing and error handing 
- Git and GitHub Pages 

## Notes 

The categories include coffee spots, movies, and TV shows. Data saving and loading are wrapped inside 'try...catch' blacoks to prevent browser storage errors from breaking the page, and all ratings are rendered dynamically as star characters.
