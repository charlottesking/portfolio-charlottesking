Course Projects Showcase

Four web applications developed across the semester, demonstrating responsive layout, interactive DOM manipulation, data visualization, and AI integration.

  • Project 1: Original Developer Portfolio

    August 2026

    My foundational multi-page portfolio site engineered using semantic HTML5, CSS design tokens, Flexbox, and CSS Grid. It established core accessibility and visual hierarchy standards, strictly adhering to WCAG AA color contrast guidelines.

    Technologies: Semantic HTML5, Responsive CSS, Flexbox/Grid, Git, GitHub Pages

  • Project 2: Local Favorites Tracker

    September 2026

    An interactive client-side web application enabling users to curate, rate, and filter favorite local spots and media. Features dynamic DOM updates, real-time client-side category filtering, and persistent browser storage via localStorage without full page reloads.

    Technologies: JavaScript (ES6+), DOM Manipulation, Web Storage API (localStorage), Form Validation

  • Project 3: Analytics & Data Dashboard

    October 2026

    A data visualization dashboard engineered to ingest structured data sets and render responsive, accessible metrics for fast decision-making. Built with modular JavaScript and dynamic UI components that support real-time data sorting and multi-criteria filtering.

    Technologies: Data Parsing, JavaScript, CSS Grid Architecture, Responsive Visualization

  • Project Zed: Don't Poison Yourself (Allergen Guard)

    October 2026

    An AI-assisted web application designed to scan personal care and cosmetic product ingredient lists against customizable user allergy profiles. Includes instant ingredient string normalization and matching, an interactive 48-hour patch-test tracker, and rolling 6-month reaction trend analytics.

    Technologies: AI-Assisted Development, Regular Expressions, String Normalization, Time-Series Analytics, localStorage
